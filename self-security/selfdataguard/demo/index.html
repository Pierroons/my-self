How this demo works

Each user has a data master key that is never stored in plaintext. It is wrapped twice — once by a key derived from their password (Argon2id), once by a key derived from their memorized secret (HMAC-SHA256). Their personal fields are encrypted by the master key with AES-256-GCM. The "Backend — raw DB view" panel on the right shows exactly what is stored on disk in real time. Watch it update after each action: an attacker who exfiltrates the SQLite file sees nothing more than what's there.
