SelfRecover

Zero-email account recovery demo — test the protocol locally

MODÈLE DE MENACE SelfRecover protège contre la compromission du serveur, le phishing, les fuites de base et le brute-force online. Il NE protège PAS contre la compromission du poste utilisateur (keylogger, info-stealer, RAT) — c'est une limite physique de toute application web. Pour les secrets sensibles (compte régalien, master key, identité de cofondation), utilise une cérémonie dédiée : Tails, Qubes OS, ou MySelf-Live (en développement, V0.2 été 2026). Entropy Lab — Trois modes de passphrase

Tout est calculé dans le navigateur — aucune passphrase ne quitte cette page. Convention SelfRecover : wordlist EFF officielle (7 776 mots, CC-BY 3.0), jamais de mini-version "pour la démo".

Méthode officielle Reinhold (1995) — recommandée

La méthode originelle du diceware. Les dés physiques produisent une entropie cryptographique au moins équivalente à celle d'un RNG logiciel — et supérieure en modèle de confiance, car elle ne dépend d'aucun ordinateur.

1
Procure-toi 5 dés à 6 faces (ou 1 dé jeté 5 fois). Pas besoin de dés certifiés pour usage courant ; pour des secrets critiques, utilise des dés en métal de qualité (pondération uniforme).
2
Télécharge la table EFF officielle (PDF, 7776 mots avec leurs codes 5 dés 11111 à 66666). Imprime-la si possible.
3
Lance les 5 dés. Lis les chiffres dans l'ordre des dés (gauche → droite). Tu obtiens un nombre du type 32145. Cherche-le dans la table → tu trouves UN mot précis (ex: 32145 → horseshoe).
4
Recommence pour chaque mot suivant. Recommandation officielle : 6 mots minimum (77,5 bits), 7+ pour secrets sensibles, 8+ pour root server.
5
Note la passphrase sur papier, range-la dans un endroit sûr (coffre, deuxième domicile de confiance). Ne la tape JAMAIS dans une application web pour vérifier — utilise l'outil offline ci-dessous.

ROADMAP V0.2 MySelf-Live — distribution Linux Live USB minimale, signée GPG, vérifiable, dédiée aux cérémonies SelfRecover. Boot RAM-only, zéro persistance, Tor disponible, PDF EFF embarqué, animation dés visuelle. Inspirée de Tails / Qubes OS, taille cible ~500 MB. Disponible été 2026. Détails.

Pas de dés sous la main ? Le navigateur peut générer une passphrase via crypto.getRandomValues() avec rejection sampling sur la wordlist EFF. Entropie strictement équivalente à la méthode physique sur la passphrase elle-même, sous réserve de confiance dans le RNG OS / navigateur.

Recover — Niveau 2 (2FA : mot mémorisé + recovery code)

Passphrase (L1) perdue ? Récupère avec ton mot mémorisé + un recovery code — sans identifiant (le code localise ton compte). Le mot est HMAC-dérivé dans le navigateur, jamais envoyé en clair. Ouvre la console DevTools pour voir la dérivation.
