SelfRecover -- Validateur diceware offline

Outil autonome, zero requête réseau. Valide une passphrase diceware contre la liste EFF officielle 7776 mots.

Air-gap recommandé. Pour usage maximalement sûr : 1. sauvegarde ce fichier sur disque ; 2. coupe le Wi-Fi et désactive l'Ethernet ; 3. ouvre le fichier en double-cliquant (URL file://) ; 4. ferme la fenêtre quand tu as fini.
Ce fichier ne contient aucune URL externe -- tu peux le vérifier avec grep -E "(http|fetch|XMLHttpRequest)" index.html
Limite physique. Cet outil ne peut pas se protéger contre un keylogger, un info-stealer ou un screen recorder déjà présent sur ta machine. Pour des secrets racine (master key, root server, identité de cofondation), utilise un OS Live signé (Tails, Qubes, MySelf-Live V0.2 à venir).

Validation d'une passphrase diceware

Tape ou colle ta passphrase. Chaque mot est vérifié comme appartenant à la liste EFF officielle. Aucune transmission, aucun storage -- tout reste dans la mémoire de cette page.

Génération aléatoire (CSPRNG navigateur)

Pas de dés ? Le navigateur génère une passphrase via crypto.getRandomValues() avec rejection sampling. Sortie volatile -- non envoyée nulle part.
